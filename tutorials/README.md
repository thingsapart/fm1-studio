# FM1 Studio tutorials

Android walkthroughs based on the original creators' guides and musical recipes.
Start with the [shared control map](CONTROLS.md), then try [your first beat](02-first-beat.md).
Use **SLOOP** for the SLOOP guides and **sloopDX** for its cheat sheet. The bundled
firmware can differ from the version shown in an upstream guide or video.
