# First beat in 60 seconds

Original source: [First beat in 60 seconds](https://github.com/isod89/sloop-fm1#your-first-beat-in-60-seconds).
Original author / creator: [isod89](https://github.com/isod89).

This is only a translation/adaptation for the **Android app** in FM1 Studio. Credit for the original material and musical ideas belongs to the creators above. Wrapper-specific substitutions are described explicitly; this is not an official replacement for their work.

Applies to: **SLOOP**. See [the shared control map](CONTROLS.md) before starting.

## The same musical sequence

1. Select **SLOOP**. Stop transport and start an empty project with **MENU → NEW PROJECT** if necessary. Select **DRUMS**, open its **▾**, and choose **808** or **BOOMBAP**. Reveal the pads with an upward swipe from the tab row.
2. Tap top **REC**. In the armed recording sheet choose **RECORD MODE FREE** for this walkthrough. Play kick, snare/clap and hats at your own tempo. Tap REC's completion action on the next downbeat to close the take; SLOOP derives the loop tempo and starts playback.
3. Tap REC during playback to overdub. For the original held-ARP roll, use **MENU → HARDWARE PANEL**, hold **ARP**, and hold HAT. Alternatively SLOOP's **PERFORM → REPEAT** enables the note-repeat layer; release/disable it after the overdub.
4. Select track 1, choose its bass sound and tap REC to record the bass over the drums. Tap REC again to leave overdub.
5. Select track 2. **PANEL → / PAGES → SEL** supplies key/scale/chord settings; choose the intended root, a suitable scale and **7TH**, then play white keys for chords. Use the hardware panel's held SEL combination if following the original keys exactly.
6. **PERFORM → FX**: hold a punch pad. MASTER controls provide DUST/DUCK. **MENU → PATTERN ACTIONS / UNDO → UNDO** recovers a mistake. Stop and save in **PROJECTS / SECTIONS**.

If REC starts at a fixed tempo rather than freely, check the native MODE setting and whether the project already contains notes. This shortcut is about SLOOP; sloopDX shares the free-take idea but has different sounds and effect counts.
