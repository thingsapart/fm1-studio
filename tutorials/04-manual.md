Applies to: **SLOOP**. See [the shared control map](CONTROLS.md) before starting.

## Everyday actions

Android: select **SLOOP**, tap a track, use its ▾ for sound/kit choices. Swipe up on the workspace tabs to reveal keys. PLAY starts all tracks; REC arms while stopped or overdubs while playing. The **PANEL → / PAGES** picker supplies native parameter groups. **STEPS** edits notes; hold a cell for its details. **MIX** supplies levels, pan, mute and solo. **SONG** stores/plays sections and edits the arrangement.

## Layers, translated

| Hold original button | Musical action | Android direct route | Android HARDWARE PANEL |
| --- | --- | --- | --- |
| FX | Punch effect while a key is held | PERFORM → FX, hold a pad | Hold FX + desired white/black key; K1 filter, K2 DUST, K3 DUCK, K4 track filter in current SLOOP |
| EDIT | Erase notes/hits | STEPS toggles cells; PATTERN ACTIONS / UNDO | Hold EDIT + sounding key; OCT− undo, OCT+ redo |
| ARP | Note repeat | PERFORM → REPEAT, enable REPEAT and hold a playing key | Hold ARP + key; K1 rate |
| SEQ | Step entry/details | STEPS; hold a cell | Hold SEQ; white keys address steps; held step exposes detail/lock knobs |
| SEL | Key/scale/chord | PANEL → SEL; KEY / SCALE FOR ALL TRACKS | Hold SEL + root key; K1 chord, K2 scale, K3 keys mode, K4 transpose |
| GLO | Mix/fill/tap tempo | MIX; PERFORM → REPEAT for fill/tap | Hold GLO; keys 1–4 mute, 5–8 solo, 9/10 fills, 16 tap tempo; K1–K4 levels |
| SAVE | Sections/song | SONG | Hold SAVE; keys 1–4 play A–D, 5–8 store, 13 loop/song, 14 arrangement recording |

Tap a family button to open its parameter pages; holding it changes key roles. Lock a layer by holding its button and tapping HOME. Release a lock with another family/HOME button; PLAY/REC/OCT retain their musical jobs inside a lock.

## Files and recovery

Android: **MENU → PROJECTS / SECTIONS** for project slots; **USER SOUNDS** for presets; **SAMPLE SLOTS / FILES** for WAV/FSMP; **DRUM SYNTH** for SYN kits; **FM6 OPERATORS / BANKS** for SLOOP FM6. Stop before imports or flash-backed saves. Export a full Android backup from **MIDI / AUDIO / FILES**.

For complete value ranges, follow the original manual; for every section's entry point see [the complete-guide crosswalk](03-complete-guide.md). sloopDX's separately mapped manual is [here](17-sloopdx-cheat-sheet.md).
